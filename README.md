# Device/DevMode Manager pour webOS TV

**🇫🇷 Français** · [🇬🇧 English](README.en.md)

Outil simple pour gérer les téléviseurs webOS TV en mode
développeur activé ou rootés

## Téléchargement

Trouvez la [dernière release](https://github.com/webosbrew/dev-manager-desktop/releases/latest) et téléchargez l'installateur pour
votre système

| Système d'exploitation           | x86_64                                     | arm64                                        | x86                                      |
|-----------------------------------|---------------------------------------------|-----------------------------------------------|-------------------------------------------|
| Windows 10+                       | webOS.Dev.Manager_[VERSION]_x64_en-US.msi   | Non disponible                                | webOS.Dev.Manager_[VERSION]_x86_en-US.msi |
| Windows 7/8/8.1 (prise en charge abandonnée) | webOS.Dev.Manager_1.13.3_x64_en-US.msi      | Non disponible                     | webOS.Dev.Manager_1.13.3_x86_en-US.msi    |
| macOS                             | webOS.Dev.Manager_[VERSION]_universal.dmg   | webOS.Dev.Manager_[VERSION]_universal.dmg     | Non disponible                            |
| Linux (Debian/Ubuntu)             | web-os-dev-manager_[VERSION]_amd64.deb      | web-os-dev-manager_[VERSION]_arm64.deb        | Non disponible                            |
| Linux (autres distributions)      | web-os-dev-manager_[VERSION]_amd64.AppImage | web-os-dev-manager_[VERSION]_aarch64.AppImage | Non disponible                            |

## Fonctionnalités

- Pas besoin d'installer le LG SDK ou une IDE
- Ajouter un appareil sans passer par la ligne de commande
- Installer des applications sur la TV en quelques clics
- Configuration compatible avec [ares-cli](https://github.com/webosose/ares-cli)
- Fonctionne sur Windows, Linux et macOS (Apple Silicon aussi !)
- Le mode sombre suit les préférences du système
